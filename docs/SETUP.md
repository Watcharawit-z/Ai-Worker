# คู่มือติดตั้งและใช้งาน

## ขั้นที่ 1 — ลองรันโหมดจำลองก่อน (5 นาที)

ยังไม่ต้องมี API key ไม่ต้องต่อ TikTok ไม่มีอะไรส่งออกไปข้างนอก

```bash
pip install -r requirements.txt
export PYTHONPATH=src
python -m aiworker --config config/demo.yaml --minutes 3
```

เปิด <http://127.0.0.1:8765> ดูหน้าจอควบคุม

โหมดนี้เร่งเวลาสิบเท่า — ตะกร้าเปลี่ยนทุก 1-2 นาทีแทนที่จะเป็นชั่วโมง
เพื่อให้เห็นการตัดสินใจครบวงจรภายในไม่กี่นาที

**สิ่งที่ควรสังเกต:**
- ตะกร้าเปลี่ยนเองเมื่อยอดไม่ถึงเกณฑ์
- แอดถูกเปิดใหม่ทุกครั้งที่ขึ้นตะกร้า
- คลิปสลับก่อนท่อนเดิมจะจบ (ไม่มีจอดำ)
- คอมเมนท์ที่ขอไลน์ถูกบันทึกไว้และแจ้งคน แต่ระบบไม่ตื่นตูมไปสลับคลิป

ถ้าตรงไหนไม่ถูกใจ แก้ตัวเลขใน `config/demo.yaml` แล้วรันใหม่

## ขั้นที่ 2 — เปิดให้ AI ตอบคอมเมนท์

```bash
cp .env.example .env
# แก้ .env ใส่ ANTHROPIC_API_KEY (ขอที่ https://console.anthropic.com)
```

โหลด `.env` เข้า environment:

```bash
export $(grep -v '^#' .env | grep -v '^$' | xargs)
python -m aiworker --config config/demo.yaml --minutes 3
```

คราวนี้คอมเมนท์ที่ไม่มีในคลังคำตอบจะถูกส่งให้ Claude ตอบ
ดูค่าใช้จ่ายจริงบน dashboard ช่อง "ค่าใช้จ่าย AI"

> ระบบตอบเฉพาะเมื่อมั่นใจเกิน 60% ที่เหลือส่งต่อให้คน
> ปรับเกณฑ์ที่ `comments.min_confidence_to_send`
> ช่วงแรกแนะนำให้ตั้งสูง (0.8) แล้วค่อยลดลงเมื่อเห็นว่าตอบดี

## ขั้นที่ 3 — ใส่ข้อมูลจริงของร้าน

### `config/knowledge/products.yaml` — สำคัญที่สุด

AI ตอบจากไฟล์นี้เท่านั้น อะไรไม่ได้เขียนไว้มันจะไม่เดา แต่จะส่งต่อให้คน

เขียนละเอียดได้เต็มที่ ไม่ต้องกลัวเปลือง — ส่วนนี้ถูก cache
จ่ายเต็มครั้งแรกครั้งเดียว ครั้งต่อไปถูกลงประมาณสิบเท่า

ยิ่ง `faq` เยอะ ยิ่งประหยัด เพราะคำถามที่ตรงกับ keywords
จะถูกตอบทันทีโดยไม่เรียก AI เลย (ฟรี)

วิธีหา keywords ที่ควรใส่: เปิดไลฟ์เก่าดูคอมเมนท์ที่ถามซ้ำที่สุด 20 อันดับแรก

### `config/baskets.yaml` — ตะกร้า 10 ใบ

เรียงตามลำดับที่จะขึ้น ระบบจะไล่ตามคิว

- `cost` ใส่ต้นทุนจริงด้วย ระบบจะได้คำนวณกำไรหลังหักค่าแอดให้
- `stock` ใส่ 0 ถ้าไม่อยากให้เช็คสต็อก
- ใบที่ของหมดจะถูกข้ามอัตโนมัติ

### `config/segments.yaml` — ท่อนวิดีโอ

อัดไลฟ์จริงไว้ ตัดเป็นท่อนละ 3-8 นาที แล้วลงทะเบียนที่นี่

| กฎการตัด | เหตุผล |
|---|---|
| ตัดให้จบประโยคเสมอ | ตัดกลางคำแล้วคนดูจับได้ทันที |
| ท่อนละ 3-8 นาที | สั้นไปสลับบ่อยจนดูแปลก ยาวไปสลับไม่ทันจังหวะ |
| ใส่ `sku` ให้ตรงกับสินค้าที่พูดถึง | ระบบจะเลือกท่อนให้ตรงกับตะกร้าที่ขึ้น |
| มีท่อนกลาง (`sku: ""`) เยอะ ๆ | เอาไว้แทรกสลับ ทำให้ไม่เป็นลูปชัดเจน |
| รวมกันอย่างน้อย 2-3 ชั่วโมง | น้อยกว่านี้จะวนซ้ำจนคนดูจับได้ |

ตรวจว่าคลิปพอไหม:

```bash
python -m aiworker --check
```

จะบอกความยาวคลิปแยกตาม SKU และเตือนตัวที่มีน้อยเกินไป

## ขั้นที่ 4 — ต่อ OBS

```bash
pip install obsws-python
```

**ฝั่ง OBS** (ทำครั้งเดียว)
1. Tools → WebSocket Server Settings → ติ๊ก Enable WebSocket server
2. ตั้ง Server Password จดไว้
3. สร้าง Scene ชื่อ `RERUN`
4. ใน Scene นั้นเพิ่ม Source → Media Source ตั้งชื่อ `SEGMENT`
   (ยังไม่ต้องเลือกไฟล์ ระบบจะเปลี่ยนให้เอง)

**ฝั่ง config**

```yaml
adapters:
  player: obs
  options:
    obs:
      host: "localhost"
      port: 4455
      password: "รหัสที่ตั้งไว้"
      scene: "RERUN"
      media_source: "SEGMENT"
```

ทดสอบ:

```bash
python -m aiworker --minutes 2
```

ถ้าเห็น `ต่อ OBS ... สำเร็จ` แปลว่าใช้ได้ — ดูใน OBS ว่าไฟล์เปลี่ยนตามจริงไหม

> `path` ใน `segments.yaml` ต้องเป็น path ที่เครื่องที่รัน OBS มองเห็น
> ถ้ารันคนละเครื่อง ต้องใช้ path ที่ share กันได้

## ขั้นที่ 5 — ต่อคอมเมนท์จริง

```bash
pip install TikTokLive
```

```yaml
adapters:
  comments: tiktok
  options:
    tiktok:
      unique_id: "@ชื่อบัญชีของคุณ"
```

ค่านี้คืออ่านคอมเมนท์เข้ามาเท่านั้น ส่วนการ **ส่งคำตอบกลับ** และ **ปักตะกร้า**
TikTok ไม่เปิด API ให้ ต้องกดในหน้าเว็บ — ทำได้ในขั้นถัดไป

## ขั้นที่ 6 — ให้ระบบปักตะกร้าและตอบคอมเมนท์เอง

ทั้งสองอย่างกดในหน้าเว็บได้ ระบบจึงเปิดเบราว์เซอร์ค้างไว้แล้วกดให้

```bash
pip install playwright
playwright install chromium
python scripts/calibrate_browser.py
```

เอาผลที่ได้ไปใส่ `config.yaml` แล้วเปิดใช้:

```yaml
adapters:
  shop: browser
  comment_sender: browser
```

**เริ่มด้วย `dry_run: true` เสมอ** — มันจะหาปุ่มให้ดูในล็อกโดยยังไม่กดจริง
เห็นว่าหาถูกทุกครั้งแล้วค่อยเปลี่ยนเป็น `false`

รายละเอียดทั้งหมด รวมถึงวิธีแก้เมื่อ TikTok เปลี่ยนหน้าเว็บ อยู่ใน
[BROWSER.md](BROWSER.md)

## ขั้นที่ 7 — เปิดแจ้งเตือน

ค่าเริ่มต้นพิมพ์ลง terminal ซึ่งไม่มีประโยชน์ถ้าไม่ได้นั่งเฝ้า

**Telegram**

1. ทัก [@BotFather](https://t.me/BotFather) พิมพ์ `/newbot` เอา token มา
2. ทักบอทที่สร้าง แล้วเปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` หา chat id
3. ใส่ใน `.env`:
   ```
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_CHAT_ID=...
   ```
4. `pip install httpx` แล้วแก้ config: `notify: [console, telegram]`

**Discord / Slack / n8n** — ใช้ `webhook` แทน ใส่ `NOTIFY_WEBHOOK_URL` ใน `.env`

ระบบส่งเฉพาะเรื่องระดับ medium ขึ้นไป และเรื่องเดิมส่งซ้ำไม่เกินทุก 5 นาที
เพื่อไม่ให้เป็นการรบกวน

## คุมหลายช่องพร้อมกัน

ทำ config แยกไฟล์ต่อช่อง แล้วรันคนละ process

```bash
python -m aiworker --config config/channel-a.yaml &
python -m aiworker --config config/channel-b.yaml &
```

อย่าลืมตั้ง `web.port` ให้ต่างกัน และ `shop.channel_id` ให้ไม่ซ้ำ
(แจ้งเตือนจะได้บอกได้ว่ามาจากช่องไหน)

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| `AI ปิด (โหมดกฎล้วน)` | ยังไม่ได้ export `ANTHROPIC_API_KEY` เข้า environment |
| `ไม่มีท่อนวิดีโอให้เล่นต่อ` | `segments.yaml` ว่าง หรือไม่มีท่อนที่ตรงกับ SKU และไม่มีท่อนกลางเลย |
| `ต่อ OBS ไม่สำเร็จ` | ยังไม่เปิด WebSocket ใน OBS / รหัสผ่านผิด / port ไม่ตรง |
| ตะกร้าเปลี่ยนถี่เกินไป | เพิ่ม `baskets.min_minutes_per_basket` |
| แอดถูกปิดเร็วเกินไป | เพิ่ม `ads.min_spend_before_judging` หรือลด `ads.kill_roas` |
| AI ตอบผิดบ่อย | เพิ่ม `comments.min_confidence_to_send` เป็น 0.8 และเติมข้อมูลใน `products.yaml` |
| แจ้งเตือนถี่เกินไป | ระบบกันซ้ำ 5 นาทีอยู่แล้ว ถ้ายังถี่แปลว่ามีปัญหาจริงหลายเรื่อง |
| จอดำระหว่างเปลี่ยนท่อน | ลด `stream.segment_min_seconds` หรือเช็คว่าไฟล์วิดีโอเปิดได้จริง |

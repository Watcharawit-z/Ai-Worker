# Ai-Worker — พนักงาน AI แผนกรีรันไลฟ์ TikTok

ระบบพนักงาน AI สำหรับ **ไลฟ์นายหน้าแบบรีรัน** คุมได้หลายเครื่องพร้อมกัน

เฝ้าจิ๊กซอว์ · ปักตะกร้าตามคลิป · ตอบคอมเมนท์ · เฝ้าการละเมิด · คุมต้นทุนแอด

**พนักงานไลฟ์ (คนพูดในคลิป) ยังเป็นคนเหมือนเดิม** — ระบบนี้ไม่ยุ่งกับตรงนั้น

---

## เริ่มใน 3 คำสั่ง

```bash
pip install -r requirements.txt
export PYTHONPATH=src
python -m aiworker --config config/demo.yaml --minutes 3
```

เปิด <http://127.0.0.1:8765> — ข้อมูลจำลองทั้งหมด ยังไม่ต้องต่อ TikTok ไม่ต้องมี API key

คุมหลายเครื่อง: `python -m aiworker --hub` แล้วเปิด <http://127.0.0.1:8700>

## พนักงาน AI ในแผนกนี้

| พนักงาน | แทนงานอะไร | ตัดสินใจเองได้แค่ไหน |
|---|---|---|
| `verify_watcher` | เฝ้าปริศนาจิ๊กซอว์ | **ตรวจจับและปลุกคน — ไม่เลื่อนแทน** |
| `basket_manager` | ปักตะกร้าตามที่คลิปพูดถึง | ปักเอง เตือนคนเมื่อคลิปพูดถึงของที่ไม่มี |
| `comment_agent` | ตอบคอมเมนท์ลูกค้า | ตอบเองเมื่อมั่นใจ ไม่มั่นใจส่งต่อคน |
| `compliance` | เฝ้าการละเมิด | สลับคลิป / หยุดสตรีม เฉพาะเมื่อ**เนื้อหาเราเอง**ผิด |
| `ads_manager` | คุมต้นทุนต่อการซื้อ | ขึ้น/สเกล/เปลี่ยนแอด ยอมแพ้แล้วเรียกคน |
| `live_watcher` | เฝ้าสตรีมและต่อคลิป | กู้สตรีมที่หลุด ต่อคลิปไม่ให้จอดำ |
| `notifier` | ส่งเรื่องถึงคน | เฉพาะเรื่องระดับ medium ขึ้นไป |

ทุกคนคุยผ่าน event bus ไม่มีใครเรียกใครตรง ๆ — ถอด/เพิ่มได้โดยไม่กระทบตัวอื่น

## สามเรื่องที่ต้องเข้าใจก่อนใช้

### 1. ตะกร้าเดินตามปาก ไม่ได้เดินตามนาฬิกา

รีรันคือการเปิดคลิปที่อัดไว้ **คนในคลิปพูดถึงสินค้าตัวไหน เราปักตัวนั้น**
ระบบไม่หมุนตะกร้าตามเวลาหรือตามยอดขาย เพราะคลิปเป็นคนกำหนด

คุณบอกระบบผ่าน **คิวชีต** ใน `config/segments.yaml`:

```yaml
segments:
  - id: full_20250726
    path: "media/live_20250726_full.mp4"
    duration_seconds: 7200
    cues:
      - {at_seconds: 0,    sku: SKU-001}   # เปิดด้วยเซรั่ม
      - {at_seconds: 900,  sku: SKU-003}   # 15 นาที เข้าเซตแต่งหน้า
      - {at_seconds: 2100, sku: SKU-004}   # 35 นาที สวอตช์ลิป
```

ระบบอ่านว่าเล่นมาถึงวินาทีที่เท่าไหร่ แล้วปักให้ตรง — ปักล่วงหน้า 2 วินาที
เพราะปักช้ากว่าปากคือคนดูหาของไม่เจอ

`python -m aiworker --check` จะบอกว่าคิวชีตชี้ไปยังตะกร้าที่ไม่มีจริงตรงไหนบ้าง

### 2. แอดผูกกับไลฟ์ ไม่ใช่ตะกร้า

- ขึ้นไลฟ์ใหม่ → ขึ้น GMV Max Live ตัวใหม่ **หนึ่งครั้ง**
- เปลี่ยนตะกร้าที่ปัก → **ไม่แตะแอดเลย**
- แอดของไลฟ์ที่รันอยู่แพงเกิน → ปิดตัวเก่า ขึ้นตัวใหม่ในไลฟ์เดิม

**เพดานค่าแอดคิดจากค่าคอมจริง ไม่ใช่ตัวเลขตายตัว** — ค่าคอมนายหน้า 10-40 บาท/ชิ้น
ต่างกันทุกไลฟ์ ตั้งตายตัวไม่ได้ กรอก `commission` ในตะกร้าแล้วระบบคิดให้เอง

```
ค่าคอม 40฿/ชิ้น → จ่ายค่าแอดได้ไม่เกิน 24฿/ออเดอร์
ค่าคอม 20฿/ชิ้น → จ่ายค่าแอดได้ไม่เกิน 12฿/ออเดอร์
ค่าคอม 10฿/ชิ้น → จ่ายค่าแอดได้ไม่เกิน  6฿/ออเดอร์
```

ระบบใช้ค่าคอมของสินค้าที่**ขายได้จริง**มาถ่วงน้ำหนัก ตอนยังไม่มีออเดอร์
ใช้ตัวที่ค่าคอมต่ำสุดไว้ก่อน (ระวังไว้ดีกว่าเผาเงิน)

```
ใช้ยังไม่ถึง 150฿ หรือแอดเพิ่งขึ้นไม่ถึง 20 นาที → ยังไม่ตัดสิน
CPA เกินเพดาน → ปิดแล้วขึ้นใหม่ (เว้น 30 นาทีก่อนเปลี่ยนอีกครั้ง)
CPA ≤ 35% ของค่าคอม → คูณงบ 1.3 เท่า
เปลี่ยนครบ 3 ครั้งยังแพง → หยุดยิงอัตโนมัติ เรียกคน
```

**เบรกฉุกเฉิน:** ขาดทุนสะสม (ค่าคอมที่ได้ − ค่าแอดที่จ่าย) ถึง 500฿
→ หยุดยิงแอดทันทีทั้งไลฟ์ ไม่มีข้อยกเว้น ไลฟ์ยังรันต่อแบบ organic

ตรรกะส่วนนี้เป็นโค้ดล้วน ไม่เรียก AI — เรื่องเงินต้องคาดเดาได้และอธิบายได้

### 3. จิ๊กซอว์ — ระบบปลุกคน ไม่ได้เลื่อนแทน

ปริศนานี้มีไว้ยืนยันว่ามีคนเฝ้าอยู่ ถ้าให้โปรแกรมเลื่อนแทนก็เท่ากับปิดตาระบบตรวจสอบ
ซึ่งเป็นเหตุให้โดนระงับถาวรถ้าโดนจับได้ — เสี่ยงกว่าเวลาที่ประหยัดได้มาก
ตัวเฝ้าจอจึงอ่านภาพอย่างเดียว ไม่มีโค้ดส่วนไหนควบคุมเมาส์หรือคีย์บอร์ด

แต่งานที่หนักจริงไม่ใช่การลากเมาส์ 2 วินาที — คือการเฝ้า 5 จอตลอด 24 ชั่วโมง
รอสิ่งที่มาชั่วโมงละครั้งแบบเดาไม่ได้ ตรงนั้นระบบทำแทนได้เต็มที่:

- เห็นภายใน 3 วินาที บอกชื่อเครื่องและนับถอยหลังจริง
- **ส่งภาพจิ๊กซอว์เข้า Telegram** — ดูจากมือถือรู้เลยว่าของจริงหรือเตือนผิด
- ปลุกซ้ำแรงขึ้น: ทันที → 45 วิ → 2 นาที → 3.5 นาที
- เหลือเวลาให้เดินไปเลื่อน ~4.5 นาทีจาก 5 นาทีที่ได้
- เก็บสถิติว่าเครื่องไหนพลาดบ่อย

ต้อง calibrate ก่อนใช้: `python scripts/calibrate_screen.py` (ดู [`docs/JIGSAW.md`](docs/JIGSAW.md))

## การละเมิด — แยกว่าใครเป็นคนผิด

| ใครพูด | ระบบทำอะไร |
|---|---|
| **เนื้อหาเรา** (คำตอบเรา, บทพูดในคลิป) | high → สลับคลิป · critical → **ลงไลฟ์**ทันที + เรียกคน |
| **ผู้ชมพิมพ์เอง** | บันทึก + บอกคนไปซ่อนคอมเมนท์ — ไม่สลับคลิป |

ถ้าลูกค้าพิมพ์ "ขอไลน์" แล้วเราไปสลับคลิปหนี มันไม่ช่วยอะไร เพราะคลิปเราไม่ได้ผิด
คอมเมนท์ผู้ชมที่มีปัญหาซ้ำ ๆ รวบรายงานครั้งเดียวทุก 2 นาที

ระดับที่สั่งสลับ/หยุด ปรับได้ที่ `compliance.auto_switch_segment_at` / `auto_stop_at`

## คุมหลายเครื่อง (PC 2 + MacBook 3)

```
Hub (เครื่องไหนก็ได้ 1 เครื่อง)  ←── worker ส่งเข้ามาทางเดียว
     จอรวม :8700                      PC-01  PC-02  MAC-01  MAC-02  MAC-03
```

จอรวมเรียงตามความด่วน — เครื่องที่มีจิ๊กซอว์ค้างและเหลือเวลาน้อยสุดขึ้นบนสุด
พร้อมสรุปยอดขาย/ค่าแอด/CPA รวมทุกเครื่อง

Mac กับ PC ใช้โค้ดชุดเดียวกัน ขอแค่ต่อ Hub กระจายเน็ตตัวเดียวกัน
เครื่องลูกไม่ต้องเปิด port อะไรทิ้งไว้ และ hub ล่มก็ไม่กระทบไลฟ์

วิธีตั้ง: [`docs/FLEET.md`](docs/FLEET.md)

## ข้อจำกัดที่ต้องรู้

1. **ยังต้องมีคน** ระบบส่งงานที่ตัดสินใจเองไม่ได้กลับมาให้คน
   เป้าหมายคือคนหนึ่งคนดูแล 5 เครื่องได้ ไม่ใช่ไม่มีคนเลย
2. **จิ๊กซอว์ต้องคนเลื่อน** ระบบปลุกให้ทันเท่านั้น
3. **ส่งคอมเมนท์กลับต้องคนกด** TikTok ไม่เปิด API ให้ส่ง
   ระบบร่างคำตอบไว้ให้คัดลอก — งานหนักคือคิดว่าจะตอบอะไร ไม่ใช่การพิมพ์
4. **ระบบร้านและแอดยังเป็นข้อมูลจำลอง** ยอดขายและ CPA บน dashboard
   ยังไม่ใช่ของจริงจนกว่าจะเขียน adapter ต่อ TikTok Shop / Ads API
   (โครง interface รอไว้แล้วใน `adapters/base.py`)
5. **ทดสอบด้วย `--minutes` ก่อนเสมอ** อย่าปล่อยรันทั้งกะในครั้งแรก
